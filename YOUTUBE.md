## 🎥 Video Script / Presentation Flow

### INTRO (0:00 - 0:30)
```
Hello everyone! Welcome to my channel!

Today I'm going to show you Traveloop - a travel planning application
that I built for the Odoo Hackathon 2026.

This app helps travelers plan their perfect trip with features like
itinerary building, budget tracking, and collaborative planning.

Let's dive in!
```

### DEMO SECTION (0:30 - 5:00)

**1. Dashboard Overview**
```
Let's start with the dashboard. As you can see, it's a modern dark-themed UI
with beautiful animations.

Here we have:
- Weather widget showing current location weather
- Time zone display for different cities
- Countdown timer to your next trip
- Trip templates for quick planning
- Search and filter functionality
- Budget range selector with city recommendations
- Progress tracker for planning stages
```

**2. Creating a Trip**
```
Now let's create a new trip!

I'll enter the trip name, description, and select dates.

I can choose a beautiful cover photo from our presets - like Goa, Jaipur, Ooty...

Then I can select destinations from our recommended places or use the
interactive map to pick locations.

I'll select a few places - let's say Goa, Kerala, and Mysore.

Click create - and our trip is ready!
```

**3. Trip Details**
```
Here we can see all our selected destinations.

We can add more cities, add activities to each stop,
track our budget, manage packing lists, and add notes.

Everything is saved in real-time to our Supabase database!
```

### TECH STACK EXPLAINED (5:00 - 7:00)
```
Now let me explain the technology behind Traveloop:

For the frontend, we used React with Vite for fast performance.
Tailwind CSS for styling, and Framer Motion for smooth animations.

For the backend, we used Supabase - which provides authentication,
a PostgreSQL database, and real-time features.

We also integrated OpenStreetMap for the interactive maps.

The entire app is responsive and works great on mobile!
```

### OUTRO (7:00 - 8:00)
```
That's a quick overview of Traveloop!

This project was built in just a few days for the Odoo Hackathon.
The code is available on GitHub - link in the description.

If you found this helpful, please like and subscribe!
And let me know in the comments what features you'd like to see next.

Thanks for watching! See you in the next video! 👋
```
